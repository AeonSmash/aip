# Recording the 90-second explainer

Local capture: `explainer.mp4` (kept on disk, not in git).

Published explainer: https://youtu.be/3D2cgt-ajlE

That YouTube URL is the Epic MegaGrants project media link.

The page is a timed walkthrough, about **1:18**. You do not need Unreal footage.

## Fast path

1. Open `explainer/index.html` in a browser (Edge or Chrome, full screen).
2. Hide bookmarks. Press F11.
3. Start Windows Game Bar or OBS on that window.
4. Click **Record** on the page. It counts 3–2–1, then plays.
5. Stop the capture when the last caption appears.
6. Upload to YouTube (unlisted is fine) and paste that URL into Epic’s project media field.
